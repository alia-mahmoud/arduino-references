# arduino-references

this repository serves as a reference for common hardware interfaces, communication protocols, sensors, actuators, and programming techniques.

each example includes well commented code, circuit/breadboard/wiring diagrams, and additional notes.

## repository structure

each folder contains: 
- .cpp or .ino file/sketch
- breadboard diagram and circuit schematic
- README with setup instructions

READMEs will generally contain the goal, concepts learned, parts needed, relevant diagrams, pin connections, how it works, where this is used, and possible future implementation into a larger project.

## topics

topics start out simple and generally increase in complexity. 

1. Digital I/O - introduction to breadboard anatomy and basic I/O interface in arduino and cpp
- Blink one LED
- Push button turns on LED
